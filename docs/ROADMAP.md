# ROADMAP — план до релиза v1.0

**Definition of done v1.0:** инструмент собран заново, опубликован на GitHub Pages нового репозитория и по функциям не уступает прототипу (три режима просмотра, планировщик маршрута, поиск по русским и английским названиям, фильтры, отметки изученного, RU/EN, светлая и тёмная темы). Сверх прототипа обязательны три вещи: дерево читается и управляется с телефона, первый экран не «проявляется» иконками, и ни одна цепочка не показана без честной пометки достоверности.

**Сознательно отложено за пределы v1.0:** тесты миграций localStorage (решение принято осознанно — это единственное место, где ошибка стоит живого прогресса игрока); экспорт и импорт прогресса; диплинк на технологию через хеш в URL; учёт опыта в планировщике (сколько уровней добрать); импорт сейва игры; автообновление данных по расписанию; редактор цепочек в интерфейсе.

**Приёмка каждой фазы:** `npm test` зелёный с тестами на новую логику фазы, затем прогон агента `phase-qa` по критериям «→ проверка». Правило и его границы — в `.claude/CLAUDE.md`.

## Фаза 7 — достоверность цепочек и релиз 1.0.0 ← цель пересборки №3
