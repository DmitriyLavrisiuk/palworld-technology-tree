# Статус проекта

> Обновлено: 2026-08-19 | История — `CHANGELOG.md` | Фаза: 4 «Планировщик маршрута» | Прод: https://dmitriylavrisiuk.github.io/palworld-technology-tree/

## Работает

- **Три режима просмотра**: «Дорожки» (цепочка подряд со стрелками), «Шкала уровней» (узел стоит на своём уровне, липкая линейка 1–80), «Компактно» (карточки).
- **Узел** несёт состояние двумя каналами сразу — цветом и значком: изучено, доступно, заблокировано уровнем, древняя технология.
- **Пометки достоверности**: узел и цепочка, собранные не из данных игры, несут точку и подпись «достроено»; в панели деталей — прямое предупреждение.
- **Панель деталей**: описание, требования, рецепт с материалами и станциями, отметка изученного.
- **Поиск по RU и EN одновременно** с учётом склонений: «сфера» и «sphere» дают одинаковые 17 технологий.
- **Фильтры** «только доступные», «только древние», «скрыть изученные».
- **Прогресс, язык, тема и режим** переживают перезагрузку (`useProgress`, схема версии 1). При первом запуске подхватывается прогресс прототипа — у него тот же origin.
- **Адаптивность**: на 390 px ни один режим не даёт горизонтальной прокрутки страницы; все 598 целей касания не меньше 44 px.
- Конвейер данных: `npm run scrape` собирает 588 технологий, 527 рецептов, 66 цепочек, 588 иконок.
- `npm test` (71 тест, без сети), `npm run typecheck`, `npm run lint`, `npm run build` — чисто.

## Известные проблемы

- **20 из 66 цепочек держатся на эвристике** (`stem` и `name` — 57 узлов из 269). Помечены в интерфейсе; вычитка — Фаза 7.
- **Шкала уровней на телефоне неудобна**: дорожка в 4640 px прокручивается внутри своего контейнера, но отдельного подхода для узкого экрана пока нет — это Фаза 5.
- **Первый экран грузит иконки по одной** — 588 запросов с `loading="lazy"`. Стратегия — Фаза 6.
