# Статус проекта

> Обновлено: 2026-08-20 | История — `CHANGELOG.md` | Фаза: 5 «Шкала на телефоне» | Прод: https://dmitriylavrisiuk.github.io/palworld-technology-tree/ — **актуален**, соответствует `main`

## Работает

- **Секции по классификации самой игры** (11 категорий), фильтр по категориям с сохранением выбора.
- **Три режима**: «Дорожки» (заголовок цепочки колонкой слева на ПК), «Шкала уровней», «Компактно» (карточка на цепочку с диапазоном уровней и суммой очков).
- **Секции и цепочки сворачиваются** шевронами во всех режимах; свёрнутость переживает перезагрузку.
- **Размер иконок — настройка**, пять ступеней 48–96, переживает перезагрузку. Шаг «Шкалы» растёт вместе с плиткой.
- **Настройки листом**: язык, тема, размер иконок с предпросмотром.
- **Плитка**: плашка уровня с точкой достоверности, рамка и тень как в эталоне.
- **Планировщик**: свёрнутая строка липнет снизу, раскрытая — нижний лист с затемнением и блюром.
- **Рецепт**: материалы плитками с иконками (85 иконок) и станции пилюлями с иконками (23). Иконки в панелях грузятся сразу, а не в общей очереди с деревом.
- **Избранное**: звезда на середине левой грани плитки, кнопка в деталях, лист по кнопке в тулбаре со списком по уровню и сводкой суммарных материалов. Переживает перезагрузку.
- **Пометки достоверности** во всех трёх режимах; параллельные семейства рисуются без стрелок.
- `npm test` (136 тестов, без сети), `typecheck`, `lint`, `build` — чисто.

## Известные проблемы

- **Линейка уровней не липнет по вертикали**: `sticky` внутри контейнера с `overflow-x-auto`. Решается вместе с Фазой 5 сменой модели прокрутки.
- **20 из 66 цепочек держатся на эвристике**; вычитка — Фаза 7.
- **Первый экран грузит иконки по одной**; стратегия — Фаза 6.
- Перенос прогресса из прототипа срабатывает только при первом открытии; две вкладки перезаписывают состояние друг друга; поле `version` не читается.
- Старая версия приложения, открытая из кэша, при первой записи затрёт `favorites` — то же свойство, что и у `nodeSize`. Отметки изученного и уровень при этом целы.
