## Работает

- **Прод живой.** Приложение собрано, выкачено на Pages, рендерит все 588 технологий с иконками и русскими названиями. Консоль чистая, все пути несут базовый префикс.
- **Конвейер данных**: `npm run scrape` собирает 588 технологий, 527 рецептов, 66 цепочек, 588 иконок. Контрольные суммы сходятся, пересборка воспроизводима.
- **Каркас**: Vite 8 + React 19 + TS + Tailwind v4, токены shadcn (`base-nova`), Geist, `components.json` — компоненты добавляются через `npx shadcn@latest add`.

- `npm test` (37 тестов, без сети), `npm run typecheck`, `npm run lint`, `npm run build` — чисто.

## Известные проблемы

- **20 из 66 цепочек держатся на эвристике** (`stem` и `name` — 57 узлов из 269). Помечены полем `confidence`; вычитка — Фаза 7.
- **Первый экран грузит иконки по одной.** Сейчас это 588 отдельных запросов с `loading="lazy"`. Стратегия — Фаза 6.

Три находки аудита `phase-qa` по Фазам 1–2 исправлены и закрыты тестами: заглушка `ru_Text` в рецептах, потеря 19 вариантов в учёте узлов, артефакт апострофа в именах цепочек.
