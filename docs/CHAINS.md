# Цепочки

## Зачем они вообще синтезируются

В игре 588 технологий и **всего 17 настоящих связей** между ними (поле `RequireTechnology`, почти все — на древних технологиях). 545 технологий не имеют ни одного пререквизита. Дерева как графа не существует: есть список, отсортированный по уровню.

Цепочка апгрейдов — то, что игрок хочет увидеть, а не то, что записано в игре. Поэтому она конструируется, и **каждая связь несёт метку достоверности**. Это не украшение: без метки инструмент выдаёт догадку за данные игры.

## Порядок авторитета

Пять проходов, каждый следующий работает только по тому, что не разобрали предыдущие.

| № | Проход | `confidence` | Что это |
|---|---|---|---|
| 1 | Ручные семьи из `chain-overrides.json` | `manual` | написано человеком, бьёт всё остальное |
| 2 | `RequireTechnology` — связные компоненты | `hard` | **единственные настоящие данные игры** |
| 3 | Стем внутреннего id (`..._Grade_01..07`) | `stem` | догадка, но id регулярны |
| 4 | Общий хвост id (`Wooden_houseset` / `Stone_houseset`) | `stem` | догадка |
| 5 | Существительное отображаемого названия | `name` | самая слабая догадка |

До проходов из списка вынимаются **корзины** — массовые наборы без семантики апгрейда: 124 седла и снаряжения палов, 33 набора мебели. Апгрейда там нет, ранжировать нечего.

## Текущее покрытие

Сверено на версии игры `1.0.3`, пересборка от 2026-08-19.

| | Цепочек | Узлов |
|---|---|---|
| `manual` — ручные | 41 | |
| `hard` — из игры | 5 | |
| `name` — эвристика | 16 | |
| `stem` — эвристика | 4 | |
| **Всего** | **66** | **250 (43%)** |
| В корзинах | 2 | 157 (27%) |

Из 66 цепочек **20 держатся только на эвристике** (`name` + `stem`). Довести это число до нуля — задача Фазы 7 в `ROADMAP.md`.

Шесть цепочек имеют вид `group`, а не `chain`: члены равноправны и апгрейда между ними нет (семь культур, пять модулей сфер). Такую группу нельзя рисовать со стрелками.

## Защиты от ложных склеек

Эвристики охотно объединяют несвязанное, поэтому у каждой догадки есть ограничитель:

- **Общий хвост названия.** Кластер принимается, только если отображаемые названия его членов делят хвост из слов. `Wooden/Stone/Metal Structure Set` проходит по «Structure Set»; `Pal Metal Pickaxe` + `Electric Furnace`, которые склеиваются по общему токену id, — нет.
- **Потолок размера.** Семья больше восьми по названию (и больше десяти по хвосту id) почти всегда ложная склейка и отбрасывается.
- **Список неоднозначных существительных** — `Sphere`, `Set`, `Box`, `Gun`, `Bed`, римские цифры: по ним не группируем.
- **Варианты вместо ступеней.** Суффиксы `Heat`, `Cold`, `Weight` — это «тот же тир, другой климат», а не следующая ступень. Они уезжают в `variants` и не удлиняют цепочку.

## Как править ошибку

Правки идут **только** в `scripts/chain-overrides.json`. Файл `src/data/chains.json` генерируется, правка в нём живёт до следующего запуска.

```jsonc
{
  "chains": [
    {
      "id": "pal-sphere",
      "group": "gear",
      "kind": "chain",                    // "group" — если апгрейда нет
      "name": { "ru": "Пал-сфера", "en": "Pal Sphere" },
      "members": ["...", "..."],          // порядок не важен: сортируется по уровню
      "variants": { "База": ["Вариант"] }
    }
  ],
  "exclude": ["Some_Id"]                  // запрет эвристикам трогать этот id
}
```

Затем:

```bash
npm run scrape -- --only=chains   # без сети, секунды
```

Смотреть в выводе на строку `by confidence`: перенос цепочки из `name`/`stem` в `manual` — это и есть прогресс по достоверности.

`exclude` нужен, когда технологию склеивают ошибочно, но своей семьи у неё нет: она останется в дереве одиночкой. **Быть неправильно сгруппированным и быть спрятанным — разные проблемы**, и этот файл чинит только первую.

## Именование

Имя цепочки — общий хвост названий её членов. Если хвоста нет (в русском ступени часто однословные: «Мегасфера», «Гигасфера»), берётся существительное **первого** члена: по последнему вся линейка щитов называлась бы «Древний щит». Имя вышло кривым — задать руками в `chain-overrides.json`.

## 📖 Для человека

Смысл всей затеи: игра говорит «на 20 уровне откроется Гигасфера», а игрок думает «мне нужна сфера получше». Цепочка переводит второе в первое. Но раз связей в игре нет, каждая такая линейка — авторская реконструкция, и метка достоверности честно говорит, насколько ей можно верить: `manual` — проверено глазами, `hard` — так сказано в игре, `stem` и `name` — компьютер догадался.
