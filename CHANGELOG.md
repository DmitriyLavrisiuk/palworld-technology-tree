# Changelog

История значимых изменений проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- Фильтр по категориям: поповер со списком, счётчиками и сохранением выбора.
- Настройки листом: язык, тема и размер иконок (пять ступеней 48–96, сохраняется).
- Сворачивание секций и цепочек шевронами во всех трёх режимах.
- Иконки материалов — 85 штук, новая стадия парсера `materials`.

### Changed

- Секции дерева строятся по классификации самой игры, а не по нашей эвристике: категория закодирована в пути ассета иконки. Эвристика по ключевым словам в названии удалена. Секций стало 11 вместо 5; «инструментов» в игровой таксономии нет — топоры и кирки относятся к оружию.
- Тулбар, плитка и режимы приближены к эталонному артефакту: плашка уровня с точкой достоверности, рамка и тень, заголовок цепочки слева на ПК, «Компактно» стал обзором цепочек.
- Панель маршрута в раскрытом состоянии — нижний лист с затемнением и блюром; оверлей листов усилен с 10% до 45%.
- Размер плитки задаётся из одного места вместо шести разных литералов.

### Changed

- Тулбар приведён к образцу: режимы просмотра — сегментированный блок с иконками, фильтры — круглые пилюли, поиск фиксированной ширины, сводка «изучено / всего» и очки, парный переключатель `RU|EN`, легенда цветов. Высота элементов зависит от типа указателя, а не от ширины экрана.

### Added

- Три режима просмотра, узел с состояниями, панель деталей с рецептом, поиск по двум языкам, фильтры, отметки изученного, переключатели языка и темы.
- Пометки достоверности в интерфейсе: связь, которой в игре нет, помечена на узле, у цепочки и в панели деталей.
- `useProgress` поверх localStorage: схема версии 1, защищённое чтение по полям, разовый перенос прогресса из прототипа (общий origin).

- Планировщик маршрута до цели: предшественники из цепочки и транзитивные из `RequireTechnology`, очки раздельно, требуемый уровень, суммарные материалы, блокеры отдельным списком. Панель снизу, свёрнутая по умолчанию.

### Fixed

- Маршрут выдавал настоящие связи игры за нашу реконструкцию: метка цепочки проставлялась раньше, а все 17 рёбер `RequireTechnology` лежат внутри тех же цепочек, поэтому ветка «из игры» не срабатывала ни разу. Один и тот же узел был помечен в маршруте и не помечен в дереве.
- Пометка достоверности появилась в свёрнутой строке панели — это состояние по умолчанию на телефоне, и без неё маршрут молчал о том, что на 6/7 состоит из реконструкции.
- «1 шагов»: склонение вынесено в общий помощник и покрыто тестами. Из 588 маршрутов 404 состоят ровно из одного шага.
- Подсветка маршрута получила значок: раньше это было единственное состояние узла, передаваемое только цветом.
- Планировщик не считает пререквизитами членов цепочек вида `group`: семь культур и пять модулей сфер равноправны, и требовать ягодную плантацию ради пшеничной было бы выдумкой. В прототипе такой проверки не было.
- По итогам аудита `phase-qa`: стрелки прогрессии больше не рисуются между вариантами того же тира и между ступенями, разделёнными фильтром — в обоих случаях они утверждали порядок, которого нет.
- Цели касания в панели деталей доведены до 44 px; штатная кнопка закрытия заменена своей — та была 28 px и подписана по-английски в русском интерфейсе.
- Пометка достоверности в режиме «Компактно» получила подпись: одна фиолетовая точка без словаря там ничего не значила.
- `TechNode` принимает достоверность цепочки, а не булев флаг: пропустить пометку молча больше нельзя.
- Атрибут `lang` документа следует за выбранным языком; поле «мой уровень» переживает очистку.

### Added

- Конвейер данных перенесён из прототипа: парсер (`scripts/`, четыре источника), ручные цепочки, типы и константы игры, данные и 588 иконок. `npm run scrape` воспроизводит данные побайтно.
- Документация конвейера: `docs/DATA_PIPELINE.md`, `docs/DATA_MODEL.md`, `docs/CHAINS.md`.
- Каркас приложения: Vite 8, React 19, Tailwind v4, токены shadcn `base-nova`, шрифт Geist. Загрузка данных динамическим `import()` тремя отдельными чанками.
- Первая выкатка на GitHub Pages: https://dmitriylavrisiuk.github.io/palworld-technology-tree/
- Тесты (Vitest): инварианты сгенерированных данных, правила сборки цепочек, валидация ручных правок и индексы загрузчика — 45 штук без сети. Приёмка фазы — `npm test` плюс агент `phase-qa` — вшита в процесс и в ROADMAP.

### Fixed

- Заглушка локали `ru_Text` в рецептах: `usable()` применялся только к названиям технологий, из-за чего три станции «Gigantic Furnace» ушли в данные непереведёнными. Русские имена станций и материалов теперь выводятся из карты имён на каждом прогоне.
- Учёт узлов в `stats`: 19 вариантов не попадали ни в одно слагаемое, поэтому `inChains + bucketed + ungrouped` давало 569 из 588, а покрытие занижалось до 43% вместо 46%.
- Апостроф в именах цепочек: `words()` заменял его пробелом, и цепочка называлась «Lily s Spear».

### Changed

- Критерий Фазы 7 переведён с покрытия на достоверность: цель — свести узлы в `stem` и `name` к нулю, а не поднять долю узлов в цепочках.

- React-плагин Vite — на SWC вместо babel-версии: `@vitejs/plugin-react@6` требует `@babel/core@8`, а `shadcn` тянет `@babel/core@7`, и дерево не разрешается.

### Fixed

- Число технологий без пререквизитов: 545, а не 544 как в документации прототипа — там не учли, что `Special_ElectricHatchingPalEgg` несёт два гейта сразу.

## [0.1.0] — 2026-08-19

### Added

- Бутстрап проекта: система документации (`docs/` с контракт-шапками, STATUS/CHANGELOG/ROADMAP), `.claude/CLAUDE.md` с архитектурными правилами, настройки Claude Code с разрешениями и хуком линтера, агенты `phase-qa`, `security-audit`, `ui-consistency`.
- Git-процесс: pre-commit с oxlint и `gitleaks protect`, Conventional Commits, GitHub Flow, dependabot.
- GitHub MCP через официальный remote-сервер, токен только из переменной окружения.
- Публичный репозиторий `DmitriyLavrisiuk/palworld-technology-tree`, `main` опубликован.
- План до релиза v1.0: восемь фаз с проверяемыми критериями, цель — паритет с прототипом плюс мобильная вёрстка, скорость первого экрана и достоверность цепочек.
